# SEO skill

## Keyword placement
- Primary keyword: title, H1, first 100 words, URL slug
- Secondary keywords: H2s naturally (never stuffed)

## Metadata
- Title tag <= 60 chars with the benefit. Meta description 140-160 chars with a verb + payoff
- One H1 only; descriptive H2/H3 hierarchy (no level skips)

## On-page
- Images: descriptive filenames + alt text; < 200KB (WebP first)
- Internal links: 3+ per post with descriptive anchors (never "click here")
- External links: only authoritative sources, rel as needed
- Schema.org: Article for posts, HowTo for tutorials, FAQPage if Q&A section

## Readability (ranked by search engines)
- Paragraphs <= 3 lines; bullets over walls of text; Flesch reading ease > 50
- Answer the search intent in the first screen (position zero patterns)

## Checklist
- [ ] Primary keyword in title/H1/first-100/slug
- [ ] Meta title + description present and within limits
- [ ] 3+ internal links, alt text on all images
- [ ] Page answers the query in the first viewport
