# Teleprompter script skill

## Conventions
- Budget ~150 words per minute; mark section timings
- Bold = spoken on camera. [STAGE] = director note. Fenced code = on-screen terminal
- Structure: hook (0:00-0:20) -> context -> demo beats -> recap -> CTA

## Write for the ear
- Short sentences (max 20 words spoken). Contractions always ("we're", "it's")
- Verbal signposts: "now here's the thing", "watch what happens when"
- Numbers: round when spoken (about three milliseconds), exact on screen
- No acronyms unless expanded once; no URLs spoken aloud (show them)

## Demo beats
- Every demo: setup (1 line) -> action -> result -> so-what. Never silent typing > 15s

## Scrub rules (hard)
- No tenant IDs, tokens, IPs, internal hostnames - use <PLACEHOLDER>
- Attribute benchmarks to the project; never invent numbers

## Checklist
- [ ] Timings sum to the target duration - 10%
- [ ] Read aloud test: no tongue-twisters, no breath-sentence > 20 words
- [ ] Every [STAGE] has a matching visual or prop prepared
