# Blog post style guide
- Title states the problem or the payoff (not the technology alone); H1 first line of the draft
- Immediately after the H1, emit the SEO block, exactly two lines:
  SEO title: "<= 60 chars, keyword + benefit>"
  Meta description: "<140-160 chars, verb + payoff>"
- Intro: the pain in 2 sentences, the promise in 1 - under 80 words
- Body: H2 sections, each ONE idea, each opening with its conclusion (inverted pyramid)
- Depth: a concept post is 800-1200 words; a tutorial post 1200-1800. Expand every demo beat from the source into its narrative (setup, action, result, so-what) - do not compress the source into a summary
- Code blocks: executable, copy-pasteable, language-tagged, expected output shown as comments. Never invent commands or configs absent from the source - describe them in prose instead
- Visual slot every 2-3 sections (diagram, screenshot, or illustration - see visual-design skill) with alt text
- Voice: practitioner to practitioner, first person allowed, opinions encouraged, active voice, concrete numbers
- Close: "What we learned" (3 bullets max) + a References/Sources section with links
- No marketing voice
