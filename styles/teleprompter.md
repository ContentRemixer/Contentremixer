# Teleprompter script style guide
- Spoken-word budget ~150 wpm; bold = spoken on camera; [STAGE] = director note; fenced code = on-screen terminal
- Structure: hook -> context -> demo beats -> recap -> CTA
- Scrub rules: no tenant IDs, no tokens, no IPs, no internal hostnames; hosts and secrets as <PLACEHOLDER>
- Attribute upstream performance numbers to the project, never invent benchmarks
